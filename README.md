# Uber-Feminino-Girassol-Rotas-
💖 Sobre o Projeto

Desenvolvido para a disciplina de Matemática Computacional Aplicada (Trabalho A3), este projeto simula um sistema de transporte onde tanto motoristas quanto passageiras são mulheres. Além da segurança de gênero, o sistema permite que a passageira bloqueie vias específicas que ela deseja evitar, recalculando automaticamente a rota mais segura e eficiente.
